# TaskCalendar

Приложение «Календарь задач» для Android.

## Функционал (в разработке)
- Список задач
- Добавление и редактирование
- Календарное представление
- Напоминания

## Технологии
- Kotlin
- Room
- MVVM
- Coroutines / Flow

## Сборка
Открыть проект в Android Studio, нажать Run.
